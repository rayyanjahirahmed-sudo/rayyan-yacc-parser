Examples

Valid:

  • while (x < 10) x = x + 1;
  • while (x > 10) x = x - 1;
  • while (x < 10) x = x * 2;
  • while (x > 10) x = x / 2;
  • while (x < 10) x = x;

Invalid:

  • while (x = 10) x = x + 1;
  • while (x < 10) x = x % 2;
