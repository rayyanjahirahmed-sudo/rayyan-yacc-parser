Valid Examples

  • while (x < 10) x = x;
  • while (x < 10) x = x + 1;
  • while (x > 10) x = x - 1;
  • while (x <= 10) x = x * 2;
  • while (x >= 10) x = x / 2;
  • while (x != 10) x = x + 1;

Invalid Examples

  • while (x = 10) x = x + 1;
  • while (x < 10) x = x % 2;
  • while x < 10 x = x + 1;
  • while (x < 10) x + 1;
  • while (x < 10) x = ;

Grammar

WHILE_LOOP → while ( CONDITION ) STATEMENT ;

CONDITION  → EXPRESSION REL_OP EXPRESSION

STATEMENT  → ID = EXPRESSION

EXPRESSION → TERM ((+ | -) TERM)*

TERM       → FACTOR ((* | /) FACTOR)*

FACTOR     → ID | NUMBER | ( EXPRESSION )

REL_OP     → < | > | <= | >= | == | !=
