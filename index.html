While-Loop Parser

Parse a while-loop using the specified YACC grammar.

Enter a while-loop and click Parse.

Tokens

No tokens generated.

Parsing Process

No parsing performed.

Grammar

stmt:
      WHILE '(' expr ')' stmt
    | ID ASSIGN expr SEMICOLON
    ;

expr:
      ID LT NUMBER
    | ID GT NUMBER
    | ID PLUS NUMBER
    | ID MINUS NUMBER
    ;

Examples

Valid

  • while (x < 10) x = x + 1;
  • while (x > 10) x = x - 1;
  • while (count < 100) count = count + 5;

Invalid

  • while (x = 10) x = x + 1;
  • while (x < 10) x = x * 2;
  • while (x <= 10) x = x + 1;

Arithmetic Expression Parser

Parse arithmetic expressions using the specified YACC grammar.

Enter an expression and click Parse.

Tokens

No tokens generated.

Parsing Process

No parsing performed.

Grammar

expression:
      expression '+' expression
    | expression '-' expression
    | expression '*' expression
    | expression '/' expression
    | '(' expression ')'
    | '-' expression %prec UMINUS
    | NUMBER
    ;

Operator Precedence

%left '+' '-'
%left '*' '/'
%right UMINUS

Examples

Valid

  • 10 + 5
  • 10 + 5 * 2
  • (10 + 5) * 2
  • -10 + 5
  • 10 / 2 - 3

Invalid

  • 10 +
  • * 10
  • (10 + 5
  • 10 / / 2
  • 10 + abc
