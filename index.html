Valid Examples

  • while (x < 10) x = x;
  • while (x < 10) x = x + 1;
  • while (x > 10) x = x - 1;
  • while (x < 10) x = x * 2;
  • while (x > 10) x = x / 2;

Invalid Examples

  • while (x = 10) x = x + 1;
  • while (x < 10) x = x % 2;
