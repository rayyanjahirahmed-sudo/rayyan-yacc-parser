About YACC

YACC stands for Yet Another Compiler-Compiler. It is a tool used to generate parsers from grammar rules.

Problem Statement

The aim of this project is to create an arithmetic expression parser using YACC. The parser supports addition, subtraction, multiplication, division and parentheses.

Example: 

(10 + 20) * 5

Sample Input and Output

Input

(10 + 20) * 5

Output

Valid expression

Procedure

  1. Create the grammar rules.
  2. Write the grammar in a YACC file.
  3. Generate the parser using YACC/Bison.
  4. Compile the generated parser.
  5. Run the parser.
  6. Enter an arithmetic expression.
  7. Check whether the expression is valid.
