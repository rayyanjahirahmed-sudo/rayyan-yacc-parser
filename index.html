While-Loop Parser

Parses while statements containing assignments, arithmetic expressions and comparison expressions.

Grammar

stmt → WHILE '(' condition ')' stmt → ID '=' expression ';' condition → expression comparison expression expression → expression '+' term → expression '-' term → term term → term '*' factor → term '/' factor → term '%' factor → factor factor → NUMBER → ID → '(' expression ')' → '-' factor comparison → '<' → '>' → '<=' → '>=' → '==' → '!='

Examples

Valid

  • while (x < 10) x = x + 1;
  • while (x > 10) x = x - 1;
  • while (x < 10) x = x * 2;
  • while (x < 10) x = x / 2;
  • while (x <= 100) x = x + x;
  • while (x != 0) x = x / 2;
  • while (x + 5 > 10) x = x * 2;
  • while ((x + 5) > 10) x = (x + 2) * 3;

Invalid

  • while (x = 10) x = x + 1;
  • while (x < 10) x = ;
  • while (x < 10) = x + 1;
  • while (x < 10) x = * 2;

Arithmetic Expression Parser

Parses arithmetic expressions using operator precedence, parentheses and unary minus.

Grammar

expression → expression '+' expression → expression '-' expression → expression '*' expression → expression '/' expression → '(' expression ')' → '-' expression → NUMBER

Examples

Valid

  • 3 + 5
  • 10 - 2 * 3
  • (5 + 2) * 4
  • -10 + 5
  • 10 / 2 + 3

Invalid

  • 3 +
  • * 5
  • (3 + 5
  • 3 ** 5
